# 复盘模板（TEMPLATE）

> 借鉴 loong-workflow `core/checklists/retrospective.md` 五段式 + 行动项四条硬约束。
> 用法：复制本文件为 `docs/retrospectives/YYYY-MM-DD-<主题>.md`，逐段填写，
> 写完对照文末自检表打勾。命名规则与 chaiflow 仓 retrospectives/ 一致。
